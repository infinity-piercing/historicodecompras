🧭 Como funciona

• Importe a base de clientes e cada planilha mensal pelo botão Importar.
• O mês é detectado automaticamente pela coluna de data (Paid at / Created at).
• Os dados ficam gravados na planilha (aba BASE_CLIENTES + uma aba por mês).
• Cada mês importado entra no histórico e no gráfico de evolução.
• Cliente que comprou em 2+ meses = recompra.
• Só pedidos com status pago entram na receita.
